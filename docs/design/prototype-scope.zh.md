# 《最后一间教室》原型收束草案

本文把宏观设计方向收束成第一版 10-15 分钟 Godot 原型范围。它是后续 PRD、任务拆分和 Godot 实现的基础草案。

## 原型目标

做一个可玩的叙事探索垂直切片，验证：

- 单一教室空间能否承载完整情绪弧线。
- 测绘、拍照、登记能否自然转化为叙事交互。
- 局部记忆显影能否用低成本 2D 资产完成有效演出。
- 占位图 + 结构化描述能否支撑后续 AI 美术替换。

目标时长：10-15 分钟。

## 玩家体验弧线

1. **车上钩子**：主角跟随单位坐车前往测绘地点。负责人说出目的地名称，主角疲惫麻木地靠在车座上，隐约觉得听过这个地方，但没有多想。
2. **进入现场**：玩家以测绘人员身份进入废弃教室，接收拆除前记录任务。
3. **职业距离**：玩家按流程拍照、测量、登记，看到教室只是破败建筑。
4. **浅层松动**：粗略看见黑板涂写或旧课桌，先触发儿时乡村学校/初中的浅层快乐记忆，而不是直接想起女同学。
5. **地点扰动**：撤并通知、旧地图或校名牌让地点名背后的记忆开始回涌，但主角仍习惯性压下。
6. **第一次明显破防**：角落里的纸飞机、断铅笔和作文本碎页让悲凉涌上来，对讲机工作信息把他拉回现实。
7. **空间变厚**：档案、座位表、墙报、通知等线索显示这所乡村学校如何消失。
8. **私人连接与钩子回收**：旧花名册和尘封旧照片显示父亲曾借读一年，并暗示父亲当年未能发挥理想成绩的隐痛。
9. **裂缝记录**：窗边裂缝既是工作内容，也预示主角心中的割裂感；他沉默后继续测绘。
10. **同代人回想**：拍照复查黑板字迹，主角想起初中、高中、大学朋友各自努力或挣扎，逐渐走向“看得到头的路”。
11. **女同学浮现**：新的作文本/刻字线索让何小满出现，她代表坦然、勇气、生命力和对来处的承认。何小满当前是暂用名。
12. **承认来处**：主角完成测绘，但无法再把这里只当成待拆建筑，也不再把自己的来处只理解为羞耻或命运。
13. **结尾余味**：主角停在女同学联系人或旧照片前，没有联系任何人；最后一张照片里，教室短暂显出曾经的样子。

## 场景结构

第一版只做一间教室，分成可读的交互区域：

- **门口/讲台区**：进入点、任务提示、测绘表、讲台、破旧门框。
- **黑板区**：主线触发点，承载粉笔字、涂写、青春记忆和最后显影。
- **课桌区**：重复资产为主，少量关键桌面藏有作文本、刻字、旧文具。
- **窗边区**：光线、尘埃、窗外施工声或乡村环境声，承载时间流动。
- **后墙/柜子区**：档案、座位表、撤并通知、奖状、墙报。

无需制作完整校园、走廊和室外地图。窗外与门外只通过声音、光线和少量背景暗示存在。

## 核心交互

### 移动与调查

- 玩家可在教室内四向移动。
- 靠近交互点时显示简洁提示。
- 调查点输出短文本、任务进度或记忆显影。

### 测绘记录

- 主角携带一张测绘记录表。
- 部分调查点会被登记为结构、损坏或遗留物。
- 记录表用作章节进度，不需要复杂 UI。

### 拍照

- 关键点允许拍照。
- 拍照后可触发现实中不存在的痕迹，例如黑板字变清楚、桌椅短暂复位、旧声音响起。
- 第一版拍照可以是固定点触发，不需要自由取景系统。

### 记忆显影

- 局部替换贴图、光照、文字和声音。
- 显影范围要小：黑板一角、一排课桌、窗边光线、讲台上的旧档案。
- 不做复杂穿越，不切换大地图。

## 关键调查点

第一版建议 11 个调查点和 1 个结尾拍照点：

1. **测绘表**：建立任务目标和职业距离。
2. **黑板涂写**：粗略触发儿时乡村学校/初中的浅层快乐记忆。
3. **破旧课桌**：触发乡村学生生活细节。
4. **墙上奖状**：显示学校曾经认真运转过。
5. **撤并通知**：揭示乡村学校消失的制度与时代原因。
6. **旧地图/校名牌**：解构开场地点名钩子，让记忆开始扰动但不完全回收。
7. **纸飞机/断铅笔**：让潜意识深处的悲凉、无措和迷茫第一次明显浮上来。
8. **旧花名册/档案柜/旧照片**：发现父亲曾借读一年，并真正回收地点名钩子。
9. **窗边裂缝**：既记录结构损坏，也预示主角心中的裂缝。
10. **黑板拍照复查**：看清更多字迹，想起不同阶段朋友各自走向“看得到头的路”。
11. **作文本碎页/女同学线索**：引出何小满和她对农村来处的坦然。
12. **最后一张照片**：结尾显影，教室短暂恢复曾经的样子。

## 美术资产粒度

### 必须做精

- 主角行走小人。
- 废弃教室主背景。
- 黑板及其涂写状态。
- 旧档案/借读记录。
- 撤并通知。
- 最后一张照片或结尾显影画面。

### 可以中等精度

- 课桌椅变体。
- 讲台、窗户、门、柜子。
- 奖状、墙报、座位表。
- 光线、尘埃、局部显影覆盖图。

### 可以粗略或占位

- 普通杂物。
- 地面、墙体重复纹理。
- 非关键破损。
- UI 框、按钮、临时音效。

## AI 资产描述规范

所有占位资产旁边应记录结构化描述，至少包含：

- **用途**：场景背景、角色、道具、UI、显影层。
- **画面内容**：主体、构图、视角、尺寸倾向。
- **风格约束**：低成本 2D、像素风或像素感、克制色彩、统一光源。
- **状态版本**：现实破败版、记忆显影版、特写版。
- **一致性锚点**：黑板位置、窗户方向、桌椅排布、主色调、年代感。
- **情绪色彩**：灰色对应迷茫麻木，亮色对应理解后的平静安全感，暗色对应压抑愤怒和痛苦回涌。
- **禁止项**：不要现代精装修、不要过度奇幻、不要高饱和卡通、不要写实照片感。

## 暂不做

- 完整校园地图。
- 多 NPC 系统。
- 自由拍照构图。
- 复杂谜题。
- 战斗、背包、经济系统。
- 多结局。
- 女同学现实登场或双向联系。

## 已确认的实现前提

- 美术方向采用“像素感 2D 插画背景 + 像素角色”。
- 命名暂用：地名 `A地`，校名 `B校`，主角 `小李`，女同学 `何小满`，父亲 `老李`。
- 第一版不使用人物插图，只使用小人 + 物件 + 文本 + 显影。
- 需要为后续人物插图保留 UI 和数据接口。
- 第一版 Godot 项目从空项目开始搭建基础移动、调查、文本框和显影系统。
