# 《最后一间教室》资产清单与 AI 生成描述 v0.1

本文整理第一版原型所需资产，服务于占位图制作、AI 图像生成和 Godot 场景搭建。目标不是一次做精所有美术，而是明确哪些必须稳定、哪些可以粗略、哪些只是占位。

## 总体美术策略

推荐方向：**像素感 2D 插画背景 + 像素角色**。

原因：

- 纯像素风对统一像素密度、动画帧和 tile 拼接要求更高。
- AI 更容易生成“像素感/低分辨率 2D 插画”背景，开发者也更容易以审美判断统一风格。
- 角色保持像素小人，可降低动画成本并贴近 RPG Maker 叙事游戏。

统一约束：

- 固定斜俯视/俯视 RPG Maker 风格视角。
- 低饱和灰色现实层，少量暖色记忆层。
- 不要现代精装修，不要高饱和卡通，不要写实照片感，不要恐怖血腥化。
- 所有 AI 生成资产都要围绕同一教室锚点：北侧黑板、南侧入口、东侧窗户、西北档案柜、三列课桌。

## 命名占位策略

地名、校名、主角名、女同学名、父亲名都属于重要设计项，当前不做最终命名。

第一版暂用：

- 地名：`A地`
- 校名：`B校`
- 主角：`小李`
- 女同学：`何小满`
- 父亲：`老李`

文本、UI 和资产 prompt 中可以使用这些占位名，但实现时应集中配置，避免散落在脚本里。后续正式命名时，必须作为一次整体设计决策替换。

## 人物插图策略

第一版不使用人物插图，只使用：

- 主角像素小人。
- 物件特写。
- 文本。
- 局部显影。

但需要为后续人物插图留白：

- 文本框 UI 预留可选头像区域，但默认隐藏。
- 对话数据结构预留 `portrait_id` 字段，但第一版为空。
- 资产目录预留 `portraits/` 或同等位置，但不在第一版生产插图。
- 父亲和何小满第一版不出现正面人物插图，只通过旧照片、作文本、声音和文本存在。

## 资产优先级

### P0：原型必须

- 主教室背景现实层。
- 主角行走小人。
- 交互物件：测绘表、黑板、撤并通知、校名牌、纸飞机/断铅笔、档案柜/花名册/旧照片、窗边裂缝、作文本碎页。
- UI：文本框、交互提示、测绘表进度、拍照闪光。
- 显影层：黑板浅层记忆、地点扰动、纸飞机情绪、父亲旧照片、黑板复查、女同学线索、最终教室复原。

### P1：增强氛围

- 车上开场静态画面。
- 联系人停留画面。
- 课桌椅变体。
- 墙上奖状、墙报、杂物、灰尘光束。
- 简单音效和环境声。

### P2：可延后

- 更丰富的桌椅破损变体。
- 多张记忆插图。
- 复杂照片 UI。
- 更细的窗外乡村背景。

## 场景与背景资产

### BG01 主教室现实层

用途：主地图背景，承载 A1-A12 全部事件。

精度：P0，必须做精。

结构化描述：

```text
用途：2D RPG Maker 风格主场景背景。
画面内容：一间即将拆除的废弃乡村教室，横向构图，斜俯视/俯视角度；北侧是一整块旧黑板，南侧偏西有入口和破旧门框，东侧一排窗户，西北有锈蚀档案柜，教室中间三列旧木课桌椅，后墙有奖状、撤并通知、旧校名牌。
风格约束：像素感 2D 插画背景，低饱和，灰色、尘土色、褪色绿色黑板，克制写实，不要照片感。
情绪色彩：现实层偏灰，表现麻木、疲惫、被时间钝化的空间。
一致性锚点：黑板在北侧，窗户在东侧，门口在南侧偏西，档案柜在西北，三列课桌从南向北排列。
状态版本：现实破败版。
禁止项：不要现代多媒体教室，不要崭新桌椅，不要恐怖血迹，不要夸张废土，不要高饱和卡通。
```

占位方案：

- Godot 初版可用色块 TileMap：墙、地面、黑板、窗、桌椅、柜子。
- 先保证动线和遮挡，再替换 AI 生成背景。

### BG02 车上开场静态画面

用途：章节 0，建立社会性麻木和地点名钩子。

精度：P1。

结构化描述：

```text
用途：开场静态画面。
画面内容：单位车辆内部，后排靠窗位置，一名年轻男性测绘人员疲惫地靠在车窗边；窗外是模糊的乡村道路和低矮房屋，前排有人影但不清晰。
风格约束：像素感 2D 插画，低饱和灰色，安静、疲惫、普通工作日氛围。
情绪色彩：灰色，表现社会性麻木和低水平好奇。
一致性锚点：主角穿普通深色工作外套，手边有文件夹或测绘包。
状态版本：开场版。
禁止项：不要豪华车辆，不要强戏剧光，不要电影海报式构图。
```

占位方案：

- 黑屏或车窗灰色背景 + 文本即可。

### BG03 最终教室复原显影层

用途：A12 结尾照片，短暂复原教室。

精度：P0，必须做精。

结构化描述：

```text
用途：结尾显影覆盖层/最终照片画面。
画面内容：与主教室同一构图，同一黑板、窗户、门、档案柜和课桌位置；桌椅短暂归位，黑板字迹更清楚，窗外暖光照进来，粉笔灰在光里浮动；没有清晰人物，只可有模糊影子、光、声音暗示过去。
风格约束：像素感 2D 插画，仍克制，不要梦幻过度。
情绪色彩：低饱和暖色，表现理解后的平静、质朴和安全感。
一致性锚点：必须与 BG01 布局一致，不能改变门窗和桌椅方向。
状态版本：记忆显影版。
禁止项：不要出现完整学生群像，不要灵异化，不要过亮天堂感，不要变成新学校。
```

占位方案：

- 在现实层上叠加暖色透明矩形、恢复几张桌椅、黑板字变清晰。

## 角色资产

### CH01 主角像素小人

用途：玩家控制角色。

精度：P0，必须做精。

结构化描述：

```text
用途：Godot 2D RPG 玩家角色行走小人。
画面内容：二十多岁到三十岁出头的男性测绘人员，普通深色工作外套，长裤，背小包或斜挎测绘包，气质疲惫、克制、普通，不突出英雄感。
风格约束：低分辨率像素小人，四向行走，RPG Maker 风格，动作简洁。
情绪色彩：默认现实层偏灰，角色不要过亮。
一致性锚点：深色外套、普通短发、测绘包。
状态版本：待机、四向行走，可选调查/拍照姿势。
禁止项：不要夸张帅气，不要西装精英，不要科幻装备，不要表情过度戏剧化。
```

占位方案：

- 先用 16x24 或 24x32 色块小人，四向 2 帧行走即可。

### CH02 父亲旧照片少年形象

用途：A8 旧照片特写或照片浮层。

精度：P0/P1，父亲线关键资产。

结构化描述：

```text
用途：旧照片中的少年父亲形象。
画面内容：一张泛黄班级合照局部，十几岁的农村少年站在第二排，短发，宽大的旧校服或朴素衣服，青春、朴实，眼睛有亮光，有一种不知道未来会怎样的自信。
风格约束：像素感 2D 插画中的旧照片质感，泛黄、颗粒、边缘磨损。
情绪色彩：淡暖色与旧照片黄，带一点时间距离。
一致性锚点：不能像现代证件照，不能过度精致。
状态版本：旧照片版。
禁止项：不要现代校服，不要明星化，不要过度清晰写真。
```

占位方案：

- 泛黄矩形 + 简单人影 + “父亲姓名”文本即可。

### CH03 何小满记忆占位

用途：女同学线。第一版不出现真人，只作为声音/文字/物件记忆。

精度：P2，可暂不生成完整角色。

结构化描述：

```text
用途：何小满相关记忆氛围，不直接登场。
画面内容：不显示完整人物；通过作文本碎页、课桌刻字、暖色光、乡村路和泥土细节暗示一个坦然、明亮、敢说自己来处的女同学。
风格约束：克制，留白，不要恋爱视觉符号堆砌。
情绪色彩：低饱和暖色，带轻微生命力。
一致性锚点：作文本题目“我的家乡……”，农村道路、玉米地、下雨泥土等记忆元素。
状态版本：记忆暗示版。
禁止项：不要正面立绘，不要青春恋爱海报，不要明确重逢。
```

占位方案：

- 只用文本和作文本碎页，无需人物图。

## UI 资产

### UI01 文本框

用途：承载叙事文本和系统提示。

精度：P0。

结构化描述：

```text
用途：RPG 叙事文本框。
画面内容：底部半透明深灰文本框，简洁边框，白色或浅灰中文文本，可显示说话人名。
风格约束：克制、可读、不要花纹装饰。
情绪色彩：深灰透明。
状态版本：普通旁白、系统提示、回忆对白。
```


### UI03 测绘表进度

用途：显示任务推进，同时反衬表格无法记录情绪。

精度：P0/P1。

结构化描述：

