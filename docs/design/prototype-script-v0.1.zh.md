# 《最后一间教室》原型剧情交互脚本 v0.1

本文是 10-15 分钟原型的第一版可玩脚本草案。目标是把宏观定调转成 Godot 中可实现的章节、调查点、文本、显影和进度状态。

## 总体结构

推荐时长：10-15 分钟。

核心循环：

> 进入区域 -> 调查物件 -> 登记/拍照 -> 触发短文本或局部显影 -> 测绘表进度推进 -> 解锁下一批调查点

核心状态：

- `survey_started`：进入教室，测绘开始。
- `blackboard_surface_memory_seen`：粗略看过黑板涂写，想起儿时乡村学校的浅层快乐记忆。
- `school_closure_seen`：看过撤并通知，知道学校消失的时代原因。
- `place_disturbance_seen`：看过旧地图/校名牌，地点名钩子被进一步解构，但还没有完全回收。
- `paper_plane_emotion_seen`：看过纸飞机/断铅笔，潜意识情绪出现明显扰动。
- `father_record_seen`：看过父亲借读记录和旧照片，真正回收地点名钩子。
- `window_crack_seen`：看过窗边裂缝，完成现实层结构记录。
- `friend_paths_seen`：拍照后进一步看清黑板字迹，想起不同阶段朋友各自走向“看得到头的路”。
- `girl_memory_seen`：看到新的线索后，女同学记忆浮现。
- `final_photo_ready`：完成前置调查，可以拍最后一张照片。
- `ending_seen`：完成结尾显影。

## 章节流程

### 0. 车上钩子

时长：1 分钟。

玩家控制：无，短开场文本或静态画面。

画面：

- 单位车辆内部，灰色低饱和。
- 主角靠在车窗边，眼神疲惫，窗外乡村道路后退。
- 不必做复杂动画，可用车窗光影缓慢移动表现行驶。

声音：

- 低频车噪。
- 远处断续谈话。
- 负责人声音略远，像从前排传来。

文本草案：

```text
负责人：今天就一处，旧校舍。到地方以后按表走，拍照、量尺寸、标危险点。
负责人：地点是——A地，B校旧址。

……

A地。

他觉得这个名字像在哪儿听过。

但车里太闷了。昨晚的表格还没填完，手机里还有三条没回的工作消息。

他把头又靠回车窗上。

只是一个地名。
```

叙事功能：

- 建立主角的社会性麻木。
- 埋下地点名钩子。
- 让玩家一开始与主角同样保持距离。

### 1. 进入教室

时长：1-2 分钟。

玩家控制：可移动、可调查测绘表。

画面：

- 教室门口，灰尘、破门框、散乱桌椅。
- 光线偏灰，低饱和。

触发：

- 玩家进入教室后，负责人或系统提示测绘任务。
- 解锁调查点 1：测绘表。

文本草案：

```text
系统：测绘记录表已展开。
系统：任务：拍摄现状照片，标记结构损坏，登记遗留物。

主角：先把该拍的拍完。
主角：别漏项就行。
```

叙事功能：

- 把玩家目标压到“完成工作”。
- 建立职业距离。

### 2. 第一轮测绘：空间只是空间

时长：2-3 分钟。

玩家控制：调查测绘表、墙上奖状、撤并通知、破旧课桌中的任意 2-3 个。

节奏：

- 文本尽量客观、短。
- 先让玩家觉得这里确实只是废弃建筑。
- 每次调查可推进测绘表进度。

建议解锁调查点：

- 测绘表
- 墙上奖状
- 撤并通知
- 破旧课桌

叙事功能：

- 展示乡村学校曾经运转过。
- 提供学校撤并和结构损坏信息。
- 让玩家习惯“测绘/登记”的工作流。

### 3. 黑板松动：浅层童年记忆浮现

时长：2 分钟。

触发条件：粗略调查黑板涂写。

画面：

- 黑板偏暗，粉笔灰、裂纹、半擦掉的字。
- 此处只让玩家粗略看见稚嫩涂写，不要完全看清具体内容。

显影：

- 黑板上的涂写不直接指向女同学，而是触发更近、更浅层的乡村学校记忆。
- 画面可短暂出现低饱和暖色：田野、操场、奔跑的孩子、粉笔灰和课桌影子，不出现清晰人脸。

文本草案：

```text
系统：黑板西侧，粉笔残留。需拍照记录。

字迹太淡了，只能看出几道歪歪扭扭的粉笔线。

像谁写到一半，又被人笑着擦掉。

他忽然想起很久以前的放学后。

田野里的风很大。
几个小孩从田埂上跑过去，书包在背后一下一下拍着。

有人抓到一只虫子，非说它会变成什么了不起的东西。

他们笑得很大声。
像那时候从来不用担心笑声会不会太大。
```

主角内心文本：

```text
他竟然笑了一下。

很轻。

轻到像是只是脸上的肌肉动了一下。

他已经很久没有在工作的时候想起这种事了。
```

叙事功能：

- 让意识层面的回忆开始苏醒，但深度仍浅。
- 黑板涂写先对应童年、玩闹和麻木生活中的一丝慰藉。
- 暂不触发女同学，避免情绪跨度过大。
- 表现主角在社会性麻木之上仍保留一点柔软反应。

### 4. 地点扰动：钩子被解构，但尚未回收

时长：2 分钟。

触发条件：调查旧地图/校名牌，且最好在看过撤并通知后。

画面：

- 后墙或柜子旁，一块旧校名牌或乡镇教育资源分布图。
- “B校旧址”名称出现。

显影：

- 车上听到的地点名短暂回响。
- 画面可压暗，叠加非常碎的声音，不完整呈现父母对话。

文本草案：

```text
系统：旧校名牌，木质，边缘腐朽。
系统：可登记为遗留物。

B校。

这几个字在他脑子里轻轻磕了一下。

像车上听见时一样。
也像更早以前。

厨房里的水声。
父亲压低的声音。
母亲说到一半又停住。

他没有继续想。
```

主角内心文本：

```text
有些名字就是这样。

你知道它们不是空的。

但只要不打开，就还能当作没听见。
```

叙事功能：

- 不直接回收开场钩子，而是让地点名背后的记忆开始涌动。
- 表明主角仍用习惯性的麻木压制让他心烦意乱的过去。
- 为后续父亲花名册真正回收钩子留出空间。

### 5. 空间变厚：学校为何消失

时长：2 分钟。

触发条件：调查撤并通知、墙报、奖状中的至少两个。

画面：

- 通知纸泛黄，盖章模糊。
- 墙报残留一半，奖状边角卷起。

文本草案：

```text
系统：关于撤并 B校 教学点的通知。
系统：原因：适龄学生数量不足，师资统一调配，学生转入镇中心学校。

他把通知拍下来。

纸上的话很完整。
完整到没有一个人需要出现。
```

可选补充文本：

```text
墙上的奖状还剩半张。
“全乡朗读比赛二等奖。”

剩下半张不知道去了哪里。
```

叙事功能：

- 让学校消失呈现为多种社会因素叠加，而非单一恶意。
- 加强“空间还在，功能已死”的感觉。
- 为父亲线和主角来处提供时代背景。

### 6. 纸飞机与断铅笔：第一次明显破防

时长：2 分钟。

触发条件：调查角落杂物；建议发生在旧地图/校名牌之后、父亲记录之前。

画面：

- 教室角落有布满灰尘和蛛网的纸飞机。
- 旁边有半截断铅笔、皱掉的作文本纸和落灰的橡皮。

声音：

- 很轻的风声。
- 对讲机突然传来工作信息，把主角从情绪里拉回现实。

文本草案：

```text
系统：角落杂物，疑似学生遗留物。

纸飞机被压在桌脚下面。
上面全是灰。

旁边有半截铅笔，断口已经发黑。

他不知道为什么，忽然觉得眼睛有点湿。

不是因为这架纸飞机。

也不全是因为这间教室。

对讲机：三组注意，东侧墙体拍完以后，记得补一张窗框细节。

他眨了一下眼。

系统：请继续测绘。
```

主角内心文本：

```text
他定了定神。

现在不是想这些的时候。
```

叙事功能：

- 让潜意识深处积压的情绪有更强扰动。
- 情绪来源混合：过去经历、压抑的自我、害怕走父亲老路的无措和迷茫。
- 用对讲机工作信息打断情绪，表现主角用理性收起情感。

### 7. 父亲记录：地点钩子真正回收

时长：2-3 分钟。

触发条件：调查旧座位表/档案柜；建议要求先完成“地点扰动”和“纸飞机与断铅笔”。

画面：

- 档案柜锈蚀，抽屉卡住。
- 旧借读登记册、花名册和一张尘封旧照片。

交互：

- 玩家调查档案柜。
- 可加入一次“抽屉卡住，再按一次打开”的轻交互。

文本草案：

```text
系统：学生花名册，年份较早，纸张受潮。

他本来只是想确认是否需要移交。

然后他看见了一个名字。

父亲的名字。

借读时间：一年。
原就读地：……
转出原因：家庭迁动。

登记册下面压着一张旧照片。

十几岁的父亲站在第二排。
头发很短，校服宽大，眼睛却很亮。

那是一种还不知道未来会怎样的人才有的亮。
```

父母回忆文本：

```text
母亲：你以前不是在 B校 借读过吗？
父亲：嗯。
母亲：那一年你不是说要好好考？
父亲：说是这么说。
母亲：也不全怪你。
父亲：没发挥出来就是没发挥出来。
父亲：人这辈子，很多事也不是想怎样就怎样。
```

主角内心文本：

```text
他皱了一下眉。

脑子里忽然浮现出现在的父亲。
中年以后，头发白得很快。

他小时候不喜欢听父亲说这种话。

那语气像一张潮湿的被子。
盖下来，不重，却让人喘不过气。

他一直怕自己也会这样。
怕有一天，也把“没办法”说得这么自然。
```

叙事功能：

- 父亲线正式进入。
- 真正回收地点名钩子：A地/B校不只是目的地，也是真实进入过父亲生命的地方。
- 让父亲的沉重不是恶意，而是自身失败感和时代局限的投射。
- 让主角的命运恐惧变具体。
- 让潜意识深处的东西开始觉醒，但仍被对讲机和工作理性暂时压回去。

### 8. 窗边裂缝：记录现实，也预示内心裂缝

时长：1-2 分钟。

触发条件：调查窗边裂缝；可在父亲记录后强化文本。

画面：

- 窗边墙体裂缝，暗色压下来。
- 外面可传来施工车辆倒车提示音，很远。

文本草案：

```text
系统：窗边墙体开裂，需标记为危险点。

他沉默着看了一秒。

然后蹲下，拍照，记录。

裂缝从窗框下面延伸到地面。

系统：危险点已标记。
```

叙事功能：

- 裂缝既是工作内容，也是主角心中裂缝的视觉预示。
- 强化“他开始准备工作，用理性压住情绪”的阶段。
- 此处比前一版更克制，不让情绪立刻爆发。

### 9. 拍照复查：朋友们各自走向看得到头的路

时长：2 分钟。

触发条件：完成父亲记录和窗边裂缝后，对黑板进行拍照复查。

画面：

- 快门后，黑板字迹比第一次更清楚。
- 不一定直接出现女同学名字，先出现更多同学式涂写、口号、日期、互相起哄的痕迹。

文本草案：

```text
快门声。

照片里的字比刚才清楚一些。

几行歪斜的名字。
一个被圈起来的日期。
还有不知道谁写下的：

“以后都要去大城市。”

他想起一些人。

初中的朋友。
高中的朋友。
大学的朋友。

那时候每个人都说以后要怎样怎样。

后来大家都在某个时间点，走上了一条看得到头的路。

有的人努力。
有的人挣扎。
有的人不再说话。
```

叙事功能：

- 在父亲线后稍微回到工作和线索收集，避免情绪连续过满。
- 把主角个人命运感扩展到同代人的共同处境。
- 为女同学线的后续出现铺垫：她不是唯一旧人，而是众多旧人里最能照见主角的一位。

### 10. 新线索：女同学浮现

时长：2 分钟。

触发条件：拍照复查后，调查课桌/作文本/黑板边缘的新线索。

画面：

- 一张作文本碎页、课桌刻字或黑板边缘涂写，让主角想起女同学。
- 暖色比童年浅层回忆更明确，但仍克制。

文本草案：

```text
抽屉里有一张皱掉的纸。

上面写着半句作文题：

“我的家乡……”

他忽然想起何小满。

她以前说起自己的村子，总像在说一件很普通的事。

门前的路。
夏天的玉米地。
下雨以后踩一脚就陷下去的泥。

她一点也不觉得这些丢人。

何小满：年轻人不谈恋爱是脑子有问题。

她说这句话的时候，好像一点也不怕别人听见。
```

主角内心文本：

```text
他说得少。

不是不知道怎么说。
是不想说。

他那时候以为，只要不说，就能离那些东西远一点。
```

叙事功能：

- 女同学线在足够铺垫后出现。
- 她承载坦然、勇气、生命力和对来处的承认。
- 让主角意识到，自己一直不是没有这些特质，而是不愿承认。

### 11. 最后测绘：完成表格，无法完成记录

时长：1-2 分钟。

触发条件：完成前置关键调查点。

画面：

- 测绘表进度已满。
- UI 显示“记录完成 / 等待最终照片”。

文本草案：

```text
系统：测绘记录已完成。
系统：请拍摄教室最终现状照片。

面积、裂缝、门窗、遗留物。

能填的都填完了。

他看着表格，忽然觉得它很干净。

干净得像什么都没有发生过。
```

叙事功能：

- 把职业流程推到终点。
- 明确“表格无法记录真正重要的东西”。

### 12. 结尾照片：短暂复原

时长：2 分钟。

触发条件：在黑板区或讲台区拍最后一张照片。

画面：

- 快门声后，教室短暂显影。
- 桌椅归位，黑板字迹清楚，窗边出现暖光。
- 不出现完整人形，最多用声音、影子、粉笔线和光表现过去。

声音：

- 很轻的朗读声。
- 桌椅移动声。
- 远处有人笑。
- 女同学一句话可以以回忆方式轻轻出现，但不要像灵异召唤。

文本草案：

```text
快门声。

照片里，教室安静地亮了一下。

桌椅像从来没有乱过。
黑板上的字还没被擦掉。
窗外的风吹进来，有粉笔灰在光里浮着。

何小满：你就是想太多。

他没有回答。

那句话已经过去很多年了。

但它没有坏。
```

手机联系人动作：

```text
他在通讯录里停了一会儿。

何小满。

屏幕暗下去之前，他没有拨出去。
```

收束文本：

```text
系统：最终照片已保存。

文件名：A地_B校旧址_最终记录.jpg

他把手机收起来。

外面有人喊他，说车要走了。

他回头看了一眼。

那间教室还是那间教室。
只是这一次，他知道它曾经不是空的。
```

叙事功能：

- 不拯救，不重逢，不补完。
- 主角完成工作，但内在视角改变。
- 教室在现实中仍会消失，但它被主角重新承认为自己来处的一部分。

## 11 个调查点草案

### 1. 测绘表

位置：门口/讲台区。

类型：必查，开启任务。

推进线索：

- 工作流程。
- 职业距离。
- 社会性麻木。

交互结果：

- 设置 `survey_started = true`。
- 解锁第一批调查点。

文本重点：

- “拍照、量尺寸、标危险点。”
- “别漏项就行。”

资产描述：

- 破旧讲台上的 A4 测绘表，夹板、黑色签字笔、角落有单位编号。
- 现实层灰色低饱和，纸张偏冷白。

### 2. 黑板涂写

位置：黑板右下或左下角。

类型：必查，浅层记忆触发。

推进线索：

- 儿时乡村学校/初中记忆。
- 放学奔跑、田野撒野、操场游戏、抓昆虫、淘气挨唠叨。
- 社会性麻木之上的一点慰藉。

交互结果：

- 设置 `blackboard_surface_memory_seen = true`。
- 只粗略看见涂写，不完全看清具体文字。

文本重点：

- “他竟然笑了一下。”
- “他已经很久没有在工作的时候想起这种事了。”

资产描述：

- 破旧黑板，粉笔灰、裂痕、半擦除字迹。
- 第一阶段涂写应模糊，只能看出稚嫩、歪斜、少年气，不暴露女同学线。

### 3. 破旧课桌

位置：课桌区前排或靠窗一张。

类型：可选但推荐，增加生活质感。

推进线索：

- 乡村学生生活细节。
- 浅层童年/少年记忆的生活质感。
- 教室曾经不是空壳。

交互结果：

- 记录遗留物或显示短记忆。

文本重点：

- 桌面刻字、旧文具、作文本碎页。
- 主角想起那些被日常麻木覆盖的小事：放学、玩闹、被长辈唠叨。

资产描述：

- 木质课桌，桌面刻痕、圆珠笔涂鸦、抽屉里有皱掉的作文本纸。

### 4. 墙上奖状

位置：后墙或黑板侧墙。

类型：可选，时代厚度。

推进线索：

- 学校曾经认真运转过。
- 乡村学校不是废墟本身，它有过秩序和荣誉。

交互结果：

- 登记墙面附着物。

文本重点：

- “全乡朗读比赛二等奖。”
- “剩下半张不知道去了哪里。”

资产描述：

- 泛黄奖状，红色边框褪色，右下角缺损。

### 5. 撤并通知

位置：后墙/公告栏。

类型：必查，时代线索。

推进线索：

- 学校消失的社会原因。
- 学生减少、师资调配、并入镇中心学校。

交互结果：

- 设置 `school_closure_seen = true`。
- 推进测绘表。

文本重点：

- “适龄学生数量不足。”
- “纸上的话很完整。完整到没有一个人需要出现。”

资产描述：

- 泛黄红头通知，印章模糊，边缘卷起，贴在破公告栏上。

### 6. 旧地图/校名牌

位置：后墙/柜子旁。

类型：必查，地点钩子扰动。

推进线索：

- 目的地名称。
- 名字背后的记忆开始回涌。
- 主角用麻木压制让他心烦意乱的过去。

交互结果：

- 设置 `place_disturbance_seen = true`。
- 播放碎片化、不完整的声音回闪。

文本重点：

- “B校。”
- “你知道它们不是空的。但只要不打开，就还能当作没听见。”

资产描述：

- 木质旧校名牌或乡镇学校分布图，字迹斑驳，局部受潮。

### 7. 纸飞机/断铅笔

位置：课桌区角落或后墙角落。

类型：必查，第一次明显情绪扰动。

推进线索：

- 潜意识积压情绪开始更强烈地浮上来。
- 悲凉、湿润、无措和迷茫。
- 对讲机工作信息打断情绪。

交互结果：

- 设置 `paper_plane_emotion_seen = true`。
- 播放对讲机打断。

文本重点：

- “他不知道为什么，忽然觉得眼睛有点湿。”
- “现在不是想这些的时候。”

资产描述：

- 布满灰尘和蛛网的纸飞机，被桌脚压住；旁边有半截断铅笔、皱掉的作文本纸和落灰橡皮。

### 8. 旧座位表/档案柜

位置：后墙/柜子区。

类型：必查，父亲线，真正回收地点钩子。

推进线索：

- 父亲借读一年。
- 父亲未能发挥理想成绩的隐痛。
- 家族式文化传递。
- 十几岁父亲的旧照片与现在中年父亲形成反差。

交互结果：

- 设置 `father_record_seen = true`。
- 要求 `place_disturbance_seen = true` 后文本更完整。

文本重点：

- “然后他看见了一个名字。父亲的名字。”
- “十几岁的父亲站在第二排。眼睛却很亮。”
- “人这辈子，很多事也不是想怎样就怎样。”

资产描述：

- 锈蚀铁皮档案柜，抽屉卡住；旧花名册纸张受潮，蓝黑墨水褪色；尘封旧照片里有青春朴实、仍带自信的父亲。

### 9. 窗边裂缝

位置：窗边区。

类型：必查，现实结构 + 内心裂缝预示。

推进线索：

- 结构损坏。
- 时间流逝。
- 主角成长中体会到的割裂感。
- 用工作理性压住情绪。

交互结果：

- 设置 `window_crack_seen = true`。
- 完成危险点标记。

文本重点：

- “他沉默着看了一秒。”
- “危险点已标记。”

资产描述：

- 老式木窗或铝合金窗，玻璃积灰，墙体裂缝向下延伸，窗外有模糊施工车辆或荒草。

### 10. 黑板拍照复查/朋友去向

位置：黑板区。

类型：必查，工作复查 + 同代人命运线。

推进线索：

- 主角回到工作流程，拍照收集线索。
- 初中、高中、大学朋友逐渐浮现。
- 当初雄心壮志的人后来各自走上“看得到头的路”。

交互结果：

- 设置 `friend_paths_seen = true`。
- 黑板字迹比第一次更清楚，但仍不直接作为结尾。

文本重点：

- “以后都要去大城市。”
- “有的人努力。有的人挣扎。有的人不再说话。”

资产描述：

- 同一块黑板的拍照复查状态，更多名字、日期、起哄式口号变清楚，但仍保持褪色和粉笔灰。

### 11. 作文本碎页/女同学线索

位置：课桌抽屉、黑板边缘或作文本碎页。

类型：必查，女同学线。

推进线索：

- 何小满浮现。
- 她对农村来处的坦然。
- 主角意识到自己不是没有勇气，而是不愿承认。

交互结果：

- 设置 `girl_memory_seen = true`。
- 解锁最后测绘完成条件之一。

文本重点：

- “我的家乡……”
- “她一点也不觉得这些丢人。”
- “年轻人不谈恋爱是脑子有问题。”

资产描述：

- 皱掉的作文本碎页，半句作文题；或课桌刻字/黑板边缘涂写，能自然引出何小满，但不需要出现她本人形象。

### 12. 最后一张照片

位置：黑板区或教室中央。

类型：结尾，显影。

前置：

- `blackboard_surface_memory_seen`
- `school_closure_seen`
- `place_disturbance_seen`
- `paper_plane_emotion_seen`
- `father_record_seen`
- `window_crack_seen`
- `friend_paths_seen`
- `girl_memory_seen`

推进线索：

- 主角释怀。
- 教室短暂复原。
- 不联系女同学，不拯救教室。

交互结果：

- 设置 `ending_seen = true`。
- 播放结尾显影。

文本重点：

- “那句话已经过去很多年了。但它没有坏。”
- “那间教室还是那间教室。只是这一次，他知道它曾经不是空的。”

资产描述：

- 最后一张照片画面：同一教室构图，现实破败层上短暂叠加暖色记忆层；桌椅归位，黑板字迹清楚，窗光更亮。

## 实现优先级

第一优先级：

- 章节 0 到章节 12 的完整流程。
- 11 个调查点和 1 个结尾拍照点。
- 文本框。
- 测绘表进度。
- 固定点拍照。
- 局部显影。

第二优先级：

- 车上开场静态画面。
- 联系人停留画面。
- 简单音效和环境声。
- 记忆显影时的光照和色彩变化。

可延后：

- 更精细的照片 UI。
- 丰富的桌椅变体。
- 可选调查文本。
- 更复杂的镜头运动。
