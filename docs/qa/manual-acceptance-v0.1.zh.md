# 《最后一间教室》手动验收脚本 v0.1

本文用于每次修改后手动跑通第一版 Godot 原型，确认 A1-A12 事件链、状态、测绘进度和基础手感没有断。

## 准备

- 运行项目主场景。
- 项目默认先进入标题页，按 `E` 或 `Enter` 开始测绘并进入教室。
- 标题页按 `Esc` 可退出。
- 项目默认以全屏窗口运行。
- 使用方向键或 WASD 移动。
- 使用 `E` 或 `Enter` 推进对话/触发交互。
- `Tab` 可展开/收起左上角测绘表；默认只显示当前目标和总进度，减少遮挡。
- `F3` 可切换调试 HUD。默认关闭。
- `F4` 可切换交互区域测试标记。默认关闭。
- `F5` 重载当前场景。
- `F6` 强制完成下一个未完成事件，用于快速跳过前置流程。
- `F7` 传送到下一个可触发事件点；如果没有可触发事件，则传送到下一个未完成事件点附近。
- 开启 `F4` 后，场景内黄色半透明区域是可交互测试区域，区域内的 `A1`-`A12` 编号对应本文验收步骤。
- 开启 `F4` 后，灰色半透明区域表示当前尚未解锁或不可触发的交互区域。
- 默认界面中，小的暖色光点表示当前阶段可推进的调查点；靠近后光点会略微加强。
- 第一版主场景已有墙体、讲台、柜子和课桌碰撞；如果卡在家具边缘，绕行即可。
- 部分未解锁调查点会显示无 `[E]` 前缀的轻提示；这类提示只说明线索存在，不能提前触发核心文本。
- 完成调查后，屏幕上方会短暂显示“已记录”反馈。
- 完成调查后，对应物件附近会留下小纸签式测绘痕迹，例如“记录”“照片”“危险”。

## 自动流程烟测

每次改动后可先跑脚本级烟测，确认 A1-A12 顺序推进、flags、测绘项、完成纸签和结尾卡没有断：

```bash
/usr/local/bin/godot --headless --path . --script res://scripts/tools/title_screen_smoke_test.gd
/usr/local/bin/godot --headless --path . --script res://scripts/tools/flow_smoke_test.gd
```

预期输出：

```text
TITLE_SCREEN_SMOKE_TEST_OK
FLOW_SMOKE_TEST_OK
```

## 验收流程

### 0. 开场

预期：

- 游戏启动后显示标题页《最后一间教室》。
- 按 `E` 或 `Enter` 后进入教室流程。
- 游戏启动后播放车上开场文本。
- 对话期间主角不能移动。
- 文本结束后进入教室，主角可移动。
- 左上角测绘面板显示当前目标：查看讲台上的测绘表。

检查：

- 调试 HUD 中当前 flags 为空。
- 测绘表 UI 默认显示当前目标和 `0/5` 总进度；按 `Tab` 后显示 5 项均未完成。

### 1. A1 测绘表

步骤：

- 移动到南侧讲台/测绘表。
- 看到 `[E] 登记`。
- 按交互键读完 A1 文本。

预期：

- 设置 `survey_started`。
- A2/A3/A4/A5 可触发。
- 对话期间不能移动。
- 左上角当前目标更新为第一批测绘。

### 2. 第一批调查 A2/A3/A4/A5

步骤：

- 调查黑板 A2。
- 调查破旧课桌 A3。
- 调查墙上奖状 A4。
- 调查撤并通知 A5。

预期：

- A2 后设置 `blackboard_surface_memory_seen`，出现浅暖色黑板显影。
- A3 后测绘进度 `遗留物登记` 完成。
- A4 或 A5 后测绘进度 `墙面附着物` 完成。
- A5 后设置 `school_closure_seen`。
- A5 会触发拍照取景框和白色快门闪光。

### 3. A6 地点扰动

步骤：

- 完成 A2 + A5 后靠近旧地图/校名牌 A6。

预期：

- A6 在前置不足时不可触发。
- 前置不足且靠近 A6 时，只显示旧牌子光线太暗的轻提示。
- 前置满足后显示 `[E] 调查`。
- A6 后设置 `place_disturbance_seen`，出现地点扰动显影。
- 左上角当前目标更新为查看角落纸飞机和断铅笔。

### 4. A7 纸飞机/断铅笔

步骤：

- 完成 A6 后调查角落纸飞机 A7。

预期：

- 设置 `paper_plane_emotion_seen`。
- 出现角落暗色显影。
- 文本中有对讲机打断。
- 左上角当前目标更新为检查档案柜里的旧记录。

### 5. A8 父亲记录

步骤：

- 完成 A7 后调查档案柜 A8。

预期：

- 设置 `father_record_seen`。
- 显示花名册、旧照片、老李相关文本。
- 出现父亲旧照片显影。

### 6. A9 窗边裂缝

步骤：

- 完成 A8 后调查窗边裂缝 A9。

预期：

- 设置 `window_crack_seen`。
- 测绘进度 `结构损坏` 完成。

### 7. A10 黑板拍照复查

步骤：

- 完成 A9 后回到黑板 A10。

预期：

- 显示 `[E] 拍照记录`。
- 触发拍照取景框和白色快门闪光。
- 设置 `friend_paths_seen`。
- 测绘进度 `现状照片` 完成。
- 出现黑板复查显影。

### 8. A11 女同学线索

步骤：

- 完成 A10 后调查课桌/作文本碎页 A11。

预期：

- 设置 `girl_memory_seen`。
- 设置 `final_photo_ready`。
- 出现女同学线索暖色显影。

### 9. A12 最后一张照片

步骤：

- 完成 A11 后到黑板前/教室中央触发 A12。

预期：

- 显示 `[E] 拍摄最终现状`。
- 触发拍照取景框和白色快门闪光。
- 设置 `ending_seen`。
- 测绘进度 `最终照片` 完成。
- 出现最终教室复原显影。
- 播放结尾文本。
- 文本结束后显示“测绘完成”收束画面。

## 回归检查

- 未解锁调查点不会提前播放核心文本。
- 已完成的一次性调查点不会重复破坏状态。
- 对话期间移动被锁定。
- 所有中文文本可读且不明显溢出文本框。
- 交互提示不遮挡文本框。
- 显影层不遮挡 UI。
- `F3` 能显示/隐藏调试 HUD。
