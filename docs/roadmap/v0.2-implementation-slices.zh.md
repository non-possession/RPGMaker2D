# v0.2 实现切片

本文把 `docs/design/v0.2-direction.zh.md` 和 `docs/design/first-space-scale-v0.2.zh.md` 中已经确定的方向拆成后续可执行任务。v0.2 先打磨第一间教室，不扩第二空间，不增加复杂解谜。

## 当前原则

- 先修空间可信度，再扩叙事表现。
- 先做系统底座，再做 A8 样板，再复用到 A11 和 A12-final。
- 每个实现切片都要能独立验证，不靠一次大改赌效果。
- 真实音频继续保持 placeholder，不作为 v0.2-A 的阻塞项。

## Slice 1：回忆事件基础系统

目标：建立 A8/A11/A12-final 共用的轻量演出能力。

范围：

- 场景文字残影：低透明文字浮现、短暂停留、淡出。
- 记忆视觉浮层：可叠加图片、色块、碎片、局部显影。
- UI 退暗：测绘/工作 UI 可短暂降透明度但不消失。
- 输入锁：支持 `0.5-1` 秒短暂停顿和 `8-12` 秒 A12-final 演出锁定。
- 演出结束回调：确保玩家、交互、UI 能恢复到正确状态。

验收：

- 能在测试事件中播放文字残影和浮层。
- 输入锁期间玩家不能移动或触发调查。
- 演出结束后输入恢复，不影响既有 A1-A12 主流程。
- 新增或扩展 smoke test 覆盖基础演出能力。

## Slice 2：A8 父亲事件样板

目标：把 A8 做成 v0.2 第一条完整视觉记忆样板。

范围：

- 档案柜/花名册视觉状态：低显著 -> 露出记录。
- 花名册字段：`学生姓名：老李`、`借读时间：一年`、`升学去向：` 空白、`转出记录：缺页`。
- 旧班级合照：少年父亲可辨但不高清。
- 查看浮层：花名册记录和旧照片并列。
- 摩托后座显影：父亲背影、车把、后视镜、土路/乡镇路、风、父亲衣角、小主角的手。
- 保留现有父亲回声，不新增承担式台词。
- 收尾：不明显失控，只锁输入 `0.5-1` 秒，然后压回工作状态。

验收：

- A8 情绪比 v0.1 更具体、更沉，但不进入崩溃。
- 玩家能理解“父亲曾经年轻、后来被现实折返、长期挡在家人前面”。
- 不直接展开母亲病情、短信、旧电脑、大学路途等后续材料。
- A8 完成后主流程继续推进。

## Slice 3：A11 何小满与空桌扩散

目标：把 A11 从文字回忆改为“作文本 -> 何小满 -> 所有孩子 -> 主角”的视觉扩散。

范围：

- 作文本碎页：贴合课桌/抽屉，不漂浮。
- 作文本内容切口：稚嫩笔迹，“未来想去美丽的江南看看”。
- 场景文字残影：朋友圈南方城市句，不模拟手机 UI。
- 图书馆/书碎片：书页、借书卡、书脊、桌面光。
- 校园卡碎片：楼梯边缘、掉落的校园卡、脚步停顿、模糊身影一角。
- 唯一清晰原话残影：“嗨，XX！你卡掉了。”
- 窗边座位显影。
- 空桌扩散：亮起桌面、翻动纸页、半截铅笔、旧书包带、椅子被推开的影子、粉笔灰。
- 不出现何小满清晰面貌，不出现清晰孩子身影。

验收：

- A11 比 A8 情绪更大，但不完整爆发。
- 玩家感到苍凉从一个作文本扩展到整间教室。
- 关系保持未被命名，不出现“友谊/爱情”判断词。
- 视觉表现替代部分文字叙述。

## Slice 4：A12-final 情绪雏形

目标：工作完成后，让 A8/A11 的记忆层安静追上来。

范围：

- 最终照片预览。
- 复用 A8/A11 视觉元素，不新增全新记忆内容。
- 安静逐层浮现：黑板粉笔痕、花名册空白栏、旧照片、摩托背影、作文本、朋友圈文字、校园卡、窗边座位、空桌痕迹。
- 工作 UI 退暗但不完全消失。
- 输入锁定 `8-12` 秒。
- 文本碎片化，不使用完整崩溃独白。
- 演出后退回现实教室，安静收束，悬而未决。

验收：

- 玩家能感到主角第一次无法继续假装没事。
- 不进入新场景。
- 不完整爆发。
- 结尾是停顿，不是治愈。

## Slice 5：第一空间可控分层重构

目标：支撑 v0.2 的可玩性基础，解决 v0.1 的比例、拼贴、碰撞和动画问题。

当前进度：

- 已完成第一轮代码基线：主角 generated sprite 按 `56px` 视觉高度和脚底 pivot 对齐。
- 已给生成背景模式补充黑板、墙面物件、窗边墙体、档案柜和 `112x44px` 双人课桌碰撞。
- 已将交互点拆分为“物件位置”和“可站热点”，避免测试/调试把玩家传送进黑板、墙面或档案柜。
- 已给纸飞机/断铅笔、档案/花名册、作文本碎页补充接触阴影和依附底座，先用运行时锚点降低漂浮贴片感。
- 已检查原 CH01 sheet：每帧可见像素高度稳定为 `54px`，底部边距稳定为 `5px`。
- 已新增 `assets/sprites/characters/ch01_surveyor_player_sheet_v02.png`，把可见人物预烘焙到 `56px` 高度，并固定脚底 pivot；运行时优先使用 v0.2 sheet，避免 `1.037037` 非整数缩放造成像素 shimmer。
- v0.2 sheet 生成时只取最大连通身体区域，剔除右向帧中与身体分离的地面影子，避免身体本体被错误缩小；角色移动速度调整为 `120px/s`，60fps 下每帧 2px，并启用 2D pixel snap 与运行时坐标取整。
- 行走动画节奏从高速双帧互闪调整为 `中立-左步-中立-右步`，约 `5fps`，优先避免长按方向时四肢“颤动式前进”的反馈。
- 已新增 `scripts/tools/first_space_scale_smoke_test.gd`，验证 v0.2 尺寸和碰撞基准。
- 已新增 `scripts/tools/player_motion_visual_smoke_test.gd`，验证 generated player 在静止/移动帧、四方向间保持相同 position、scale、centered 配置。headless 环境不产出截图时会跳过截图，只保留指标检查。

范围：

- 按 `docs/design/first-space-scale-v0.2.zh.md` 重构第一教室分层。
- 主角稳定 `56px` 视觉高度，统一动画帧画布和脚底 pivot。
- 单人课桌 `72x42px`，双人课桌 `112x44px`。
- 主要通路 `80-96px`，局部最低 `64px`。
- 黑板、课桌、档案柜、墙面不可走。
- 纸飞机、断铅笔、作文本、花名册、旧照片必须依附桌脚/地面/抽屉/档案柜。

验收：

- [done] 人物不再忽大忽小。
- [doing] 移动帧不抖动。
- [done] 玩家不能走上黑板和桌子。
- [doing] 道具不再像独立贴片。
- [done] 既有 A1-A12 流程仍可完成。
