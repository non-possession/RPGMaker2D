# v0.2 第一空间可控分层与比例规范

本文记录 v0.2-A 的第一批设计决策：不扩展第二空间，不增加复杂解谜，先把第一间教室打磨成具备可信调查互动感的空间。

## v0.2-A 目标

v0.2-A 的核心目标不是增加内容量，而是修复空间可信度：

- 人物比例稳定，不再忽大忽小。
- 移动动画稳定，不再因帧尺寸或 pivot 不一致而抖动。
- 桌子、黑板、档案柜等固定物件不能被玩家走上去。
- 纸飞机、断铅笔、作文本等道具必须贴合桌脚、地面或抽屉，不再像独立贴片。
- 交互提示、拍照反馈、完成标记都应锚定到具体物件。

更完整的 v0.2 高层方向、父亲线、何小满线和 A12-final 边界记录在 `docs/design/v0.2-direction.zh.md`。

## 视觉方向

v0.2 继续采用像素风 / RPG Maker 可控小人方向。

- 逻辑视口继续使用 `960x540`。
- 暂不要求生成 `1920x1080` 源图。
- 美术精修方向是更协调、更清楚、更可交互，不转向手绘 2D 插画风。
- 回忆照片可以比主场景更有情绪，但仍要服务像素/RPG Maker 主体。

## 空间动线

第一空间采用“入口建立整体感 -> 逐步靠近细节 -> 后段回看”的动线。

- 门口/入口阶段先让玩家看清黑板、课桌列、窗户、档案柜的大轮廓。
- 工作调查阶段让玩家确认空间没有危险，保持测绘工作状态。
- 记忆松动阶段让细节开始变私人。
- 回看阶段让同一空间改变意义，而不是靠切换新地点制造推进。

课桌布局采用“视觉上略微凌乱，逻辑上保持网格可控”的原则：

- 双人课桌为主，按 2-3 列形成教室秩序。
- 少量桌椅可以轻微偏移、缺角、错位、掉漆。
- 关键调查物所在桌必须更稳定、更可读。
- 主要通路不低于 `80px`，局部可低到 `64px` 但不能成为必经主路。
- 碰撞仍以规则形状为主，不跟着视觉小破损变复杂。

## 尺寸基准

以下尺寸作为 v0.2-A 第一轮资产和碰撞校准标准。

| 项目 | 标准尺寸 | 说明 |
| --- | --- | --- |
| 逻辑视口 | `960x540` | 项目内坐标、截图、场景校准的基础尺寸。 |
| 主角站立高度 | `56px` | 所有角色和家具比例的主尺子。 |
| 主角动画帧高度误差 | `1-2px` | 不同动作帧视觉高度不得明显变化。 |
| 单人课桌 | `72x42px` | 适合放作文本、纸张、旧文具等小道具。 |
| 双人课桌 | `112x44px` | v0.2 推荐主桌型，兼顾乡村教室气质和角色比例。 |
| 双人课桌上限 | `128x44px` | 仅在特殊构图中使用，避免再次让人物显得过小。 |
| 最小可通行走道 | `64px` | 确保 56px 角色可通过，不用于主要调查动线。 |
| 舒适调查走道 | `80-96px` | 主要调查路线优先使用的通行宽度。 |

## 角色动画规则

- 所有主角帧使用统一画布尺寸。
- 脚底 pivot 固定在同一位置。
- 禁止通过缩放制造走路变化。
- 每帧角色视觉高度应稳定在 `56px` 附近。
- 若帧内需要头发、衣摆、背包轻微摆动，只能在画布内变化，不改变脚底位置。

## 教室分层规则

v0.2-A 从整图背景过渡到可控分层场景。

| 层级 | 内容 | 目的 |
| --- | --- | --- |
| 地面层 | 地板、墙面底色、基础光影 | 提供统一空间基底。 |
| 固定大件层 | 黑板、桌椅、档案柜、门窗 | 提供碰撞和空间结构。 |
| 可调查道具层 | 纸飞机、断铅笔、作文本、花名册、旧照片 | 提供具体互动锚点。 |
| 角色层 | 主角小人 | 保持统一比例和 Y-sort。 |
| 遮挡层 | 桌沿、柜子前景、部分椅背 | 提供前后关系。 |
| 反馈层 | 拍照框、显影、完成纸签、回忆照片 | 提供交互反馈。 |
| UI 层 | 对话框、测绘表、设置菜单 | 不参与场景遮挡。 |

## 碰撞规则

- 黑板、墙面、讲台、档案柜、课桌主体必须不可走。
- 玩家可从桌椅之间通行，但主调查动线不应低于 `80px` 宽。
- 碰撞形状优先贴合“脚能不能站”的区域，不追求完全贴合视觉边缘。
- 任何新增固定物件，都必须同时记录视觉尺寸、碰撞尺寸和交互热区。

## 道具贴合规则

- 纸飞机、断铅笔应贴在桌脚或地面阴影边缘。
- 作文本碎页应放在课桌面、抽屉口或桌内，不独立悬浮。
- 花名册、旧照片应和档案柜或桌面发生接触关系。
- 小道具必须有接触阴影或遮挡关系，避免像 UI 图标贴在背景上。

## 调查物显著性规则

调查物物理上提前存在，但视觉显著性随流程分阶段增强。

- 关键道具一开始可以低对比、被桌沿遮住、在阴影里、只露一角。
- 流程推进后，通过光线、显影、交互提示、完成标记或镜头反馈提高显著性。
- 不突然凭空生成完整物件，除非它属于回忆照片或显影层。
- 同一物件可以有普通状态和被注意到状态。
- 交互权限可以晚开放，但空间上要提前有合理解释。

## 回忆照片和显影规则

回忆照片采用“场景内显影为主，独立照片为关键节点补强”的策略。

- 局部显影用于黑板、桌面、窗边、档案柜附近，让空间自己浮出记忆。
- 独立照片只用于关键节点，例如 A8 父亲旧照片、A11/A12 的何小满相关影像或最终照片。
- 独立照片不要频繁弹出，避免变成视觉小说式 CG 收集。
- 照片出现后应回到场景，让玩家意识到照片是这间教室的一层记忆。
