# 《最后一间教室》资产生产 Brief v0.1

本文把原型中的色块、文字显影和临时道具，整理成下一步可交给 AI 图像生成或素材网站检索的生产规格。目标是先替换最能验证“低美术成本 2D 叙事游戏”的资产，而不是一次性追求完整美术。

## 统一规格

第一版目标风格：

- 像素感 2D 插画背景 + 低分辨率像素小人。
- 固定 RPG Maker 斜俯视/俯视视角。
- 主场景横向画布，当前逻辑分辨率为 `960x540`。
- 现实层低饱和灰、褪色绿、尘土色。
- 记忆层少量暖色，但保持克制。
- 不使用血腥、惊吓、灵异化视觉，不做青春恋爱海报感。

文件建议：

- 背景整图：`PNG`，不透明，`960x540`。
- 道具/显影覆盖：`PNG`，透明背景，按实际物件边界裁切。
- 角色小人：`PNG` sprite sheet，透明背景。
- 原始 AI 输出保留在 `assets/originals/`，二次裁切/压缩后的游戏内资源放在 `assets/sprites/`。

## 资产替换优先级

### 第 1 批：验证叙事空间成立

优先替换：

- `BG01` 主教室现实层。
- `BG03` 最终教室复原显影层。
- `OBJ02` 黑板三状态。
- `CH01` 主角小人。

理由：

- 这四项决定“一个小空间承载时空变迁”的核心体验。
- 资产数量少，但能显著提升玩家对原型的感知。
- 其余道具仍可用色块和标签占位。

### 第 2 批：验证情绪线索成立

优先替换：

- `OBJ05` 纸飞机/断铅笔。
- `OBJ06` 档案柜/花名册/父亲旧照片。
- `OBJ08` 作文本碎页。
- `OV03` 纸飞机情绪显影。
- `OV04` 父亲旧照片显影。
- `OV06` 何小满记忆显影。

理由：

- 这些资产对应浅层童年记忆、父亲线、女同学线。
- 如果它们成立，就能验证“温柔刺痛”的核心情绪是否可由低成本图像承载。

### 第 3 批：增强工作流与质感

优先替换：

- `OBJ01` 测绘表。
- `OBJ04` 撤并通知。
- `OBJ07` 窗边裂缝。
- UI 纸签、取景框、测绘表面板。
- 环境灰尘、窗光、暗角。

理由：

- 这些增强主角的测绘身份和空间质感。
- 第一阶段用 Godot 原生色块即可。

## 画面同构要求

以下资产必须共享同一教室布局：

- `BG01` 主教室现实层。
- `BG03` 最终教室复原显影层。
- `OBJ02_C` 黑板最终显影状态。
- `OV07` 最终教室覆盖层。

共同锚点：

- 北侧大黑板。
- 东侧窗户。
- 南侧偏西入口。
- 西北档案柜。
- 中间三列课桌。
- 墙上奖状、撤并通知、旧校名牌。

如果 AI 输出改变了门窗方向、课桌排列或黑板位置，应视为不可直接使用。

## 第一批 Prompt

### BG01 主教室现实层

```text
资产 id：BG01_main_classroom_reality
输出规格：960x540 PNG，不透明背景。
用途：Godot 2D RPG 主地图背景，承载 A1-A12 全部调查事件。
画面内容：一间即将拆除的废弃乡村教室，横向构图；北侧是一整块旧绿色黑板，东侧一排窗户，南侧偏西有入口和破旧门框，西北有锈蚀档案柜；教室中间有三列旧木课桌椅；墙上有旧奖状、撤并通知、旧校名牌；地面有灰尘、纸屑、轻微裂纹。
构图与视角：RPG Maker 风格斜俯视/俯视视角，角色可以在教室内行走；黑板在画面上方，课桌由上到下排列，窗户在画面右侧。
风格：像素感 2D 插画背景，克制写实，低分辨率游戏场景感，不要照片感。
色彩与情绪：低饱和灰色、尘土色、褪色绿色；现实层偏灰，表达疲惫、麻木、被时间钝化。
一致性锚点：黑板北侧、窗户东侧、入口南侧偏西、档案柜西北、三列课桌、墙上奖状和撤并通知。
透明背景：否。
禁止项：不要现代多媒体教室，不要崭新桌椅，不要恐怖血迹，不要夸张废土，不要高饱和卡通，不要写实照片。
```

### BG03 最终教室复原显影层

```text
资产 id：BG03_final_classroom_memory
输出规格：960x540 PNG，可不透明；若作为覆盖层使用，需提供透明背景版本。
用途：A12 最终照片后的短暂显影画面，与 BG01 同构。
画面内容：与 BG01 同一间教室、同一门窗和课桌位置；桌椅短暂归位，黑板字迹更清楚，窗外有低饱和暖光照入，粉笔灰在光里浮动；空间看起来安静、温暖但不梦幻；不出现清晰人物，可以有很淡的模糊影子或声音感暗示过去。
构图与视角：必须与 BG01 保持同一 RPG Maker 斜俯视/俯视构图，不能改变黑板、窗户、入口、档案柜和课桌方向。
风格：像素感 2D 插画，克制，仍像真实旧教室的记忆显影。
色彩与情绪：低饱和暖色，表达理解后的平静、质朴、安全感。
一致性锚点：黑板北侧、窗户东侧、入口南侧偏西、档案柜西北、三列课桌。
透明背景：优先生成不透明整图；可再生成透明覆盖层版本。
禁止项：不要完整学生群像，不要灵异化，不要天堂式强光，不要变成崭新学校，不要改变空间布局。
```

### OBJ02 黑板三状态

```text
资产 id：OBJ02_blackboard_three_states
输出规格：横向 sprite sheet PNG，透明背景；三帧等宽排列，每帧约 300x70。
用途：黑板调查、拍照复查、最终显影的局部替换资产。
画面内容：同一块旧绿色黑板的三种状态。第一帧：粉笔灰和半擦除痕迹，只能粗略看到稚嫩涂写。第二帧：拍照后字迹更清晰，有几个名字、日期、以及“以后都要去大城市”的字样。第三帧：最终显影，黑板字迹短暂完整，带低饱和暖光。
构图与视角：正对或轻微俯视的黑板局部，道具可直接贴到 BG01 北侧黑板位置。
风格：像素感 2D 道具，文字可读但不要过密。
色彩与情绪：第一帧灰绿、第二帧稍暗且清晰、第三帧低饱和暖色。
一致性锚点：三帧必须是同一块黑板，同样边框、同样磨损位置。
透明背景：是。
禁止项：不要现代白板，不要电子屏，不要恐怖涂鸦，不要密密麻麻的小字。
```

### CH01 主角小人

```text
资产 id：CH01_surveyor_player_sprite
输出规格：透明背景 sprite sheet；建议 4 方向，每方向待机 1 帧 + 行走 2 帧，单帧 24x32 或 32x40。
用途：玩家控制角色。

构图与视角：RPG Maker 风格小人，四方向：下、左、右、上；动作简洁，适合低成本动画。
风格：低分辨率像素小人，边缘清楚，动作可读。
色彩与情绪：深色外套、低饱和现实层颜色，角色不要过亮。
一致性锚点：深色外套、普通短发、测绘包。
透明背景：是。
禁止项：不要夸张帅气，不要西装精英，不要科幻装备，不要表情过度戏剧化。
```

## 接入顺序

1. 先接入 `BG01`，保持现有碰撞、交互点、UI 不变。
2. 接入 `CH01`，替换当前 Polygon2D 小人，但保留 `player.gd` 行走逻辑。
3. 接入 `OBJ02` 黑板三状态，先用 Sprite2D 覆盖现有黑板色块。
4. 接入 `BG03` 或 `OV07`，替换最终显影色块。
5. 接入第二批关键道具。
6. 最后再微调交互点位置、纸签位置和提示点位置。
