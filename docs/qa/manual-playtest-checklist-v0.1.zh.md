# 《最后一间教室》v0.1 手动验收清单

本清单用于一次完整人工手测。手测时不要使用 `F6` 或 `F7`，除非正在定位问题。

## 运行信息

- 日期：
- 设备/系统：
- 窗口状态：全屏 / 窗口
- 是否使用耳机：
- 结论：通过 / 有条件通过 / 不通过

## 完整流程

- [ ] 从标题页按 `E/Enter` 进入。
- [ ] 读完车内开场，不出现卡住或跳字。
- [ ] 不使用调试跳关完成 A1-A12。
- [ ] A12 后出现结尾卡“测绘完成”。
- [ ] 退出或关闭游戏无异常。

## 动线与交互

- [ ] A1 测绘表容易找到。
- [ ] 第一批调查点 A2/A3/A4/A5 不需要乱试太久。
- [ ] A6 右侧墙旧地图/校名牌能按目标文案找到。
- [ ] A7 左下角纸飞机/断铅笔能按目标文案找到。
- [ ] A8 左侧档案柜能按目标文案找到。
- [ ] A9 右侧窗边裂缝能按目标文案找到。
- [ ] A10 回到黑板拍照复查的意图清楚。
- [ ] A11 中排课桌作文本碎页不容易漏掉。
- [ ] A12 教室中央最终照片的位置和目标文案一致。
- [ ] 靠近调查点时提示显示“动作：物件名”，没有歧义。

## UI 与表现

- [ ] 左上测绘表不遮挡关键物件。
- [ ] 对话框不遮挡必须观察的线索。
- [ ] 拍照取景框和快门反馈足够明显，但不刺眼到影响阅读。
- [ ] 显影层能被看见，且不会和测绘表争抢注意力。
- [ ] 完成纸签有“已记录”的反馈感。
- [ ] 结尾卡居中，文字不溢出。

## 音频

- [ ] 环境底噪不刺耳、不压过文本。
- [ ] 快门声明确但不突兀。
- [ ] 纸张/档案柜音效不尖锐。
- [ ] 记忆/终局音色不煽情过度。
- [ ] 全流程没有突然过响的声音。

## 文本与情绪

- [ ] 开场地名钩子能被注意到，但不显得刻意。
- [ ] A7 对讲机打断成立。
- [ ] A8 父亲记录自然回收前文钩子。
- [ ] A10 朋友去向过渡自然。
- [ ] A11 何小满线索在文本中成立。
- [ ] A12 结尾收得住，没有强行煽情或解释过满。

## 问题记录

使用以下格式记录问题：

```text
- [severity: high|medium|low] 步骤：问题描述。建议处理方式。
```

## 签收标准

- 所有 high 问题已修复或降级为已知限制。
- medium/low 问题已记录到 `docs/qa/manual-playtest-notes-v0.1.zh.md`。
- 至少完成一次不使用 `F6/F7` 的完整流程。
