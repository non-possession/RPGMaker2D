# v0.2 方向设计记录

本文记录 v0.2 讨论中已经收束的高层方向、叙事原则和实现边界。后续实现时以本文为方向依据，再结合 `docs/design/first-space-scale-v0.2.zh.md` 做场景与资产落地。

## 核心目标

v0.2 不扩展第二空间，不增加复杂解谜，也不靠堆更多调查点提高内容量。

v0.2 的验证目标是：在第一间教室中建立可信的调查互动感，并验证当前工作流和工具链能稳定生产这种质量。

优先级判断：

- 会破坏“我在一个真实教室里调查”的问题，优先级高于新增内容。
- 空间、碰撞、比例、动画稳定优先于新剧情。
- 叙事深化优先通过画面、回忆照片、显影和可触碰物件完成，不继续主要依赖长段文字。

## 视觉与生产方向

v0.2 继续采用像素风 / RPG Maker 可控小人方向。

- 保持 `960x540` 逻辑视口。
- 暂不要求生产 `1920x1080` 源图。
- 不转向细腻手绘 2D 插画风。
- 美术精修方向是更协调、更清楚、更可交互。
- 真实音频暂时仍保持 placeholder；当前重点是画面、分层、比例、碰撞、动画和回忆照片。

v0.1 的整图背景方案已经完成“快速产出原型”的目标。v0.2 转向可控分层场景，让背景、固定大件、可调查道具、角色、遮挡、反馈、UI 分别管理。

## 第一空间动线

第一空间采用“入口建立整体感 -> 逐步靠近细节 -> 后段回看”的动线。

玩家第一次进入陌生教室时，先从门口建立整体安全感：黑板、课桌列、窗户、档案柜的大轮廓应该先可读。玩家熟悉空间后，才逐步关注细节。

四个心理阶段：

1. 门口/入口阶段：建立整体感。
2. 工作调查阶段：确认空间没有危险，保持工作状态。
3. 记忆松动阶段：细节开始变私人。
4. 回看阶段：同一空间改变意义。

课桌布局采用“视觉上略微凌乱，逻辑上保持网格可控”的原则：

- 双人课桌为主，按 2-3 列形成教室秩序。
- 少量桌椅轻微偏移、缺角、错位、掉漆。
- 关键调查物所在桌必须更稳定、更可读。
- 主要通路不低于 `80px`，局部可低到 `64px` 但不能成为必经主路。
- 碰撞仍以规则形状为主，不跟着视觉小破损变复杂。

## 调查物显著性

调查物物理上提前存在，但视觉显著性随流程分阶段增强。

这意味着玩家不会感觉道具突然刷新出来，而是会觉得它原本就在那，只是之前没有注意到。

实现原则：

- 关键道具一开始可以低对比、被桌沿遮住、在阴影里、只露一角。
- 流程推进后，通过光线、显影、交互提示、完成标记或镜头反馈提高显著性。
- 不突然凭空生成完整物件，除非它属于回忆照片或显影层。
- 同一物件可以有普通状态和被注意到状态。
- 交互权限可以晚开放，但空间上要提前有合理解释。

## 回忆照片与显影

回忆照片策略：场景内显影为主，独立照片为关键节点补强。

- 局部显影是空间自己浮出记忆，不应频繁打断移动节奏。
- 独立照片只用于关键节点，例如 A8 父亲旧照片、A11/A12 的何小满相关影像或最终照片。
- 独立照片不要变成视觉小说式 CG 收集。
- 照片出现后应回到场景，让玩家意识到照片是这间教室的一层记忆。

## 父亲线

父亲线是向下扎根的重量。

它来自血缘、家庭、阶级、失败经验和现实边界。父亲不是单纯的“失败的人”，而是主角看见自己可能未来的一面镜子。父亲代表主角继承下来的现实压力，是河的上游，是盘根交错的血缘和家庭惯性。

v0.2 中父亲线应该具体、沉重、写实。

已定切口：

- 父亲曾在这所教学点借读一年。
- 他没能继续升学或转出去。
- 最后被迫回到原来的生活轨道。

表达方式：

- 花名册/借读记录作为冷、客观的记录层。
- 花名册推荐字段：`学生姓名：老李`、`借读时间：一年`、`升学去向：` 空白、`转出记录：缺页`。不写“失败”或“没考上”。
- 旧照片里少年父亲要比何小满更具体、更可辨认，但不做高清肖像。
- 面部保留旧照片颗粒和模糊，身份由站位、姓名记录、主角反应和台词共同确认。
- 父亲后来轻描淡写的话越平淡越重。v0.2 保留现有回声：“没发挥出来就是没发挥出来。人这辈子，很多事也不是想怎样就怎样。”
- 摩托、路和父亲背影是 v0.2 父亲线的核心生活意象。
- 摩托显影采用后座第一视角：主角看见父亲背影、车把、后视镜、土路或乡镇路、风吹衣角。
- 摩托显影可出现小时候主角的手轻轻抓住父亲衣角或后座，但不出现小主角完整形象。
- 这个视角表达“很多生活的问题都是父亲在前面遮风挡雨”，但正文不宜直白说破。

A8 父亲线是 v0.2 的第一次小峰值：主角心里一沉，但还能用“我是来工作的”压住。

父亲线的 v0.2 边界：

- 不直接展开母亲病情、短信、旧电脑、大学路途等完整材料。
- 不提前使用“父亲哭了”等最重片段。
- 不把父亲写成单一失败结论，而是写成一条沉默的路。
- 更深的依赖、羞耻、亏欠、抗拒、心疼和相似性，留给后续高潮。
- A8 只让玩家意识到：父亲曾经年轻，后来被现实折返，又在很长时间里挡在家人前面。
- 父子相似性在 v0.2 只露一丝，不明确说破；保留“他一直怕自己有一天，也会把这些话说得这么自然”的方向，不写“他发现自己正在变成父亲”。

## 何小满线

何小满线是水面上偶然照见的光。

她不是被攻略或被寻找的人物，而是主角生命里一次擦肩而过的因缘。她不是答案，她是一面镜子，照见主角内心缺失的一面：对来处的坦然、对命运的轻快、不急于证明自己的自在，以及不把失败感提前内化的能力。

何小满必须保持朦胧和留白：

- 不给清晰正脸。
- 不给完整角色立绘。
- 不让玩家把目标转成“找到何小满”。
- 不过度解释她后来如何。
- 可以使用声音、远景、背影、半张照片、作文本、窗边座位和一句记忆里的话。
- 她每次出现都应反照主角，而不是展开她自己的完整传记。

v0.2 何小满线的具体视觉切口：

- 作文本碎页。
- 窗边座位。

A11 情绪递进：

1. 作文本碎页触发稚嫩笔迹的记忆，其中一个小女孩写到未来想去美丽的江南看看。
2. 主角想起何小满朋友圈里的一句话：“和 XX 的缘分，或许从高考的时候就埋下了。”这里的 `XX` 是现实南方城市名占位，不是人名，用于连接江南、远方、各奔东西和高考分流的意象。
3. 浮现在脑海里的不是何小满本人，而是这几个字。主角已经很久没有联系她了，甚至想不起她的面貌。
4. 主角想起何小满曾经给他安利过的图书馆和书。
5. 主角又想起大学楼梯口的一件小事：他匆忙上楼，校园卡掉了，何小满从对面走来，略显嫌弃地提醒他“嗨，XX！你卡掉了。”这里 `XX` 是主角称呼占位。
6. 他捡起卡，笑了笑，继续赶路。多年之后才发现，这一幕他竟然记了这么久，甚至之前都不知道自己还记得这么清楚。
7. 通过何小满提到过的弟弟妹妹，联想到她的童年和家庭。
8. 再联想到这间教室里曾经学习过的每一个孩子，他们的家庭、父母、未来幻想和不可追回的人生。
9. 最后回到主角自己，悲天悯人的苍凉反弹成内心悲怆。

A11 的关系边界：

- 何小满与主角之间是未被命名的亲近，不明确归类。
- 不出现“友谊/爱情”这两个判断词。
- 不让主角自问“我是不是喜欢她”。
- 不写成多年等待或遗憾告白。
- 不把何小满变成单向白月光。
- 重点写当时以为会自然延续，后来才知道只是短暂交汇。
- 分离之后，那些原本普通的瞬间开始慢慢变得复杂。
- 复杂不是因为某个明确答案，而是因为人生、时空、来处、远方和命运分流都叠在一起。

A11 可保留的关键句方向：

```text
他那时以为，这样的关系会自然地继续下去。
后来才知道，很多继续，只是因为当时还没有走远。

他们都没有停下来。
那时没有。
后来也没有。
```

A11 是第二次更大的小峰值：苍凉感变大，主角开始压不住，但还没有真正崩溃。

## A8/A11/A12-final 视觉事件草图

### A8 父亲线

目标：第一次小峰值，现实重量压下来，但主角还能压住。

```text
玩家靠近西北档案柜
-> 档案柜平时存在，但低对比、半藏在阴影里
-> 交互后柜门/抽屉状态变化，花名册露出
-> 画面局部变冷，UI/测绘表略微退暗
-> 花名册局部显影：学生姓名、借读时间一年、升学去向空白、转出记录缺页
-> 登记册下方露出一张旧班级合照的一角
-> 照片短暂放大查看，但不是全屏 CG
-> 花名册记录和旧照片并列
-> 少年父亲照片渐暗，半透明浮出成年父亲背影
-> 后座第一视角短暂显影：车把、后视镜、土路、风、父亲衣角、小主角的手
-> 父亲现有平淡回声浮起
-> 画面回到档案柜，主角短暂停顿
-> 他重新收回工作状态
```

A8 查看浮层采用“花名册记录和旧照片并列”的方式。左侧是冷冰冰的登记信息，右侧是曾经年轻的少年父亲。照片先在场景内露出，再短暂放大查看。

A8 的摩托显影不是新场景，而是照片/档案浮层上的半透明记忆影像。它把“教室第二排的少年父亲”和“摩托前座的成年父亲背影”连在一起：一个曾经也站在可能性的入口，后来成为不断把家人载向远处的人。

A8 收尾边界：

- 不明显失控，只短暂停顿，然后压回工作状态。
- 显影退回档案柜后，主角站在原地停住。
- 输入锁定约 `0.5-1` 秒。
- 测绘表和工作 UI 稍微晚一点恢复。
- 不让主角后退、跪下、摇晃。
- 不出现崩溃式独白。
- 不让画面剧烈闪烁。
- 不让音效过分煽情。

可保留为内部设计句，不建议 v0.2 正文直说：

```text
原来很多风都是他挡住的。
```

更适合正文的克制句方向：

```text
他忽然想起很多路。
很多时候，他只看见父亲的背。
```

### A11 何小满线

目标：第二次更大的小峰值，从私人记忆扩展到人生苍凉。

```text
玩家回到中排/窗边课桌
-> 作文本碎页一开始已经露出一点，但此前不显眼
-> A10 后光线或提示让课桌抽屉口更明显
-> 交互后作文本碎页被看见：稚嫩笔迹、未来想去美丽的江南看看
-> 朋友圈文字残影浮现，不出现何小满本人
-> 书页、借书卡、图书馆意象短暂显影
-> 楼梯口短回忆影像雏形：楼梯边缘、掉落的校园卡、脚步停住、模糊身影
-> 唯一清晰原话可以是“嗨，XX！你卡掉了。”
-> 窗边座位微亮，风吹纸页
-> 显影从一个座位扩散到几张空桌，再回到整间旧教室
-> 主角意识到有些记忆在分离后才开始发酵
```

A11 中作文本碎页是触发核心，窗边座位是情绪扩散核心。校园卡短回忆在 v0.2 先做雏形，不做完整人物，也不使用真实配音。

A11 视觉扩散规则：

- 从单点作文本扩散到整间教室的空桌。
- 不出现清晰孩子身影，只出现痕迹：亮起的桌面、翻动纸页、半截铅笔、旧书包带、椅子被推开的影子、窗光里的粉笔灰。
- 可以有低透明坐姿轮廓，但不能可辨认。
- 朋友圈句、校园卡原话、关系余味关键句使用场景文字残影，不主要放进对话框。
- 朋友圈文字不模拟手机 UI，只保留脑内浮现的几个字。
- 校园卡回忆只用碎片叠加：楼梯边缘、掉落的校园卡、脚步停顿、模糊身影一角，不切完整大学楼梯场景。

### A12-final 情绪雏形

目标：v0.2 不爆发，只让主角第一次无法继续假装没事。

```text
玩家完成最终照片
-> 快门声/闪光，测绘记录显示完成
-> 照片预览出现：这间教室的最终现状
-> 照片显影不是普通截图，而是前面线索短暂叠层
-> 父亲花名册、旧照片一角、作文本碎页、窗边座位、黑板粉笔痕、空课桌依次浮现
-> 文本不再完整叙述，变成几组念头碎片
-> 输入短暂停顿或变慢，主角站在原地
-> 显影强度到达顶点，但不撕裂、不进新场景
-> 画面慢慢退回现实教室
-> 外面有人喊他，说车要走了
-> 他没有立刻回应
-> 安静收束，悬而未决
```

## 情绪曲线与结尾边界

v0.2 不解决主角，只让主角第一次无法继续假装没事。

情绪曲线：

```text
入口：工作状态，冷静。
A8：父亲线第一次小峰值，压住。
A11：何小满线与人生苍凉感，峰值加剧。
A12：最终照片，工作完成。
A12-final：理智防线松动，情绪雏形显影。
尾声：安静收束，但悬而未决。
```

A12-final 是 v0.2 的情绪雏形，不是完整爆发。

真正的撕裂/释放留到后续版本，并且需要新的场景设计来承载。v0.2 只做“工作完成后情绪追上来”的结构，让玩家感觉主角快撑不住了，但还没有真正释放。

A12-final 建议边界：

- 10-20 秒以内。
- 不进入新场景。
- 不出现完整崩溃独白。
- 只出现几组念头碎片。
- 显影层短暂叠加父亲、何小满、孩子们和教室。
- 复用 A8/A11 的视觉元素，不新增全新记忆内容。
- 显影节奏是安静逐层浮现，不做快速闪回。
- 演出期间短暂锁定移动和交互，建议 `8-12` 秒。
- 测绘/工作 UI 退暗但不完全消失，表达工作身份仍在，但已经挡不住记忆。
- 最后安静收束，留下伏笔。

结尾不是答案，而是停顿。这一章结束了，但真正走出来需要时间。
