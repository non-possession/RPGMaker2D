# 《最后一间教室》教室场景布局与事件流 v0.1

本文把原型脚本落成单一教室场景的空间布局、调查点可见性、事件顺序和 Godot 实现提示。目标是让后续可以直接进入资产清单和 Godot 场景搭建。

## 布局原则

- 第一版只做一间教室，不做完整校园、走廊或室外地图。
- 教室采用固定俯视/斜俯视 RPG Maker 风格视角，玩家可四向移动。
- 空间从“工作入口”逐渐引导到“记忆深处”：门口/讲台 -> 黑板/课桌 -> 后墙/柜子 -> 角落/窗边 -> 黑板复查/结尾。
- 玩家可以看到多数物件，但关键调查点通过状态逐步激活，避免一进门信息过载。
- 记忆显影只做局部覆盖：黑板一角、课桌一排、校名牌、档案柜、窗边光线、最终照片层。

## 平面布局

建议基准：一张横向教室地图，约 20 x 12 tile。黑板在北侧，门在南侧偏西，窗户在东侧，档案柜在西北/后墙区域。

```text
北 / 黑板侧
┌────────────────────────────────────────┐
│ [墙奖状]   [黑板/涂写/最终照片] [校名牌] │
│    A4             A2/A10             A6 │
│ [档案柜/花名册/旧照片]       [撤并通知] │
│        A8                         A5    │
│                                        │
│  课桌列1       课桌列2        课桌列3    │
│  A3            A11                     │
│                                        │
│ [纸飞机/断铅笔]              [窗边裂缝] │
│        A7                         A9    │
│                                        │
│ [门口] [讲台/测绘表]                  │
│        A1                              │
└────────────────────────────────────────┘
南 / 入口侧
```

调查点编号：

- **A1 测绘表**：讲台上，玩家进门后第一个明确目标。
- **A2 黑板涂写**：黑板一角，粗略触发浅层童年记忆。
- **A3 破旧课桌**：课桌区前排或靠窗一张，生活质感。
- **A4 墙上奖状**：黑板侧墙或后墙，学校曾经运转过。
- **A5 撤并通知**：后墙公告栏，时代线索。
- **A6 旧地图/校名牌**：后墙靠近黑板或柜子旁，地点扰动。
- **A7 纸飞机/断铅笔**：后排角落或桌脚下，第一次明显破防。
- **A8 旧花名册/档案柜/旧照片**：后墙柜子区，父亲线和钩子回收。
- **A9 窗边裂缝**：东侧窗边，现实结构和内心裂缝预示。
- **A10 黑板拍照复查**：黑板同一区域，父亲线后激活。
- **A11 作文本碎页/女同学线索**：课桌抽屉或黑板边缘，何小满线。
- **A12 最后一张照片**：教室中央或黑板正前方，结尾显影。

## 玩家动线

### 初始动线

玩家从南侧门口进入，视线先落到讲台和测绘表。此时黑板、课桌、奖状、撤并通知等都可见，但只有部分可调查。

推荐第一批激活：

- A1 测绘表
- A3 破旧课桌
- A4 墙上奖状
- A5 撤并通知

### 中段动线

完成 A1 后，黑板 A2 可激活。完成 A2 与 A5 后，A6 旧地图/校名牌激活。完成 A6 后，A7 纸飞机/断铅笔激活。

中段应让玩家在教室里横向移动：从黑板到后墙，再从后墙到角落。这样情绪不是站在一个点连续爆发，而是随着空间移动逐渐下潜。

### 后段动线

完成 A7 后，A8 档案柜激活。完成 A8 后，A9 窗边裂缝激活，随后 A10 黑板拍照复查激活。完成 A10 后，A11 女同学线索激活。

这一段动线从后墙档案柜到窗边，再回黑板，再回课桌。空间上形成“回看”的感觉：同一块黑板第二次看时，意义已经不同。

### 结尾动线

完成 A11 后，测绘表显示进度完成，A12 最后一张照片激活。A12 建议放在教室中央偏黑板的位置，让玩家最后站在整个空间的中轴线上拍照。

## 事件状态流

```text
Start
  -> 车上开场
  -> EnterClassroom
  -> A1 测绘表
      sets survey_started
      unlocks A2, A3, A4, A5

A2 黑板涂写
  sets blackboard_surface_memory_seen

A5 撤并通知
  sets school_closure_seen

A2 + A5
  unlocks A6 旧地图/校名牌

A6 旧地图/校名牌
  sets place_disturbance_seen
  unlocks A7 纸飞机/断铅笔

A7 纸飞机/断铅笔
  sets paper_plane_emotion_seen
  unlocks A8 档案柜

A8 档案柜/旧照片
  sets father_record_seen
  unlocks A9 窗边裂缝

A9 窗边裂缝
  sets window_crack_seen
  unlocks A10 黑板拍照复查

A10 黑板拍照复查
  sets friend_paths_seen
  unlocks A11 作文本碎页/女同学线索

A11 女同学线索
  sets girl_memory_seen
  sets final_photo_ready
  unlocks A12 最后一张照片

A12 最后一张照片
  sets ending_seen
  plays ending
```

可选调查：

- A3 破旧课桌和 A4 墙上奖状建议第一版保留，但不作为结尾硬前置。
- 若需要更强完成感，可让 A3/A4 推进测绘表百分比，但不阻塞主线。

## 可见性与提示

### 初始可见但不可调查

以下物件一开始可见，但靠近时只给轻提示或无提示，直到状态满足：

- A6 旧地图/校名牌：提示“墙上有块旧牌子，光线太暗。”
- A7 纸飞机/断铅笔：不提示，避免玩家过早注意。
- A8 档案柜：提示“柜子锈住了，稍后再看。”
- A9 窗边裂缝：提示“窗边墙体似乎有损坏。”
- A10 黑板复查：复用 A2，但需父亲线后才出现拍照复查提示。
- A11 女同学线索：藏在课桌抽屉或作文本碎页中，A10 后才可见。

### 交互提示文案

- 普通调查：`调查`
- 测绘相关：`登记`
- 拍照相关：`拍照记录`
- 最后照片：`拍摄最终现状`

提示应短，不解释功能。真正的叙事由文本框承担。

### 命名与人物插图接口

第一版命名使用占位配置：

```text
place_name = "A地"
school_name = "B校"
protagonist_name = "小李"
girl_name = "何小满"
father_name = "老李"
```

不要把这些名字硬编码到多个脚本中。后续正式命名时，应通过统一配置替换。

第一版不显示人物插图，但对话数据预留：

```text
speaker_id
speaker_name
portrait_id
text
```

`portrait_id` 第一版为空；文本框可预留头像区域但默认隐藏。

### 数据驱动建议

每个调查点用统一数据结构描述：

```text
id
label
position
required_flags
set_flags
prompt
dialogue_id
survey_progress_delta
photo_required
overlay_id
enabled_initially
```

第一版不需要复杂编辑器工具，可以先用 GDScript 字典或资源文件配置。

### 显影层

显影层建议集中放在 `MemoryOverlayRoot` 下：

- `overlay_blackboard_surface`：A2 浅层童年记忆，低饱和暖色。
- `overlay_place_disturbance`：A6 地点扰动，压暗并轻微声音回闪。
- `overlay_paper_plane_emotion`：A7 角落局部暗色/湿润感。
- `overlay_father_photo`：A8 旧照片特写或照片浮层。
- `overlay_blackboard_photo`：A10 黑板字迹更清楚。
- `overlay_girl_memory`：A11 作文本碎页暖色记忆。
- `overlay_final_classroom`：A12 教室短暂复原。

显影可以用淡入淡出，不需要复杂粒子。第一版重点是时机和文本。

## 测绘表进度

建议第一版测绘表只显示 5 个项目：

- 现状照片
- 遗留物登记
- 墙面附着物
- 结构损坏
- 最终照片

对应推进：

- A1 开启测绘表。
- A3/A7/A8 推进遗留物登记。
- A4/A5/A6 推进墙面附着物。
- A9 推进结构损坏。
- A10 推进现状照片。
- A12 推进最终照片并结束。

进度不应变成任务清单压力。它的叙事作用是反衬：表格越来越完整，但主角越来越意识到表格记不下真正重要的东西。

## 摄影交互

第一版采用固定点拍照：

- A2：粗略黑板调查可以不拍照，只是登记粉笔残留。
- A10：黑板拍照复查，触发朋友去向文本。
- A12：最终照片，触发结尾显影。

可选：

- A5 撤并通知和 A8 父亲旧照片可以用“拍照记录”提示，但本质仍是固定文本事件。

不要做自由取景系统。自由取景会显著增加 UI、截图、判定和美术压力，不适合第一版验证。

## 音频事件

第一版建议最少做 6 类声音：

- 车内低频噪声。
- 教室环境底噪：风、灰尘感、远处施工。
- 对讲机提示音：打断 A7 和父亲线后的情绪。
- 快门声：A10、A12。
- 记忆浅层声音：孩子跑动、笑声、远处朗读，不出现清晰长对白。
- 结尾外部呼喊：提醒车要走了。

声音要轻，不能压过文本。它的作用是给空间厚度，不是制造恐怖气氛。
